# Installation

1. Download `GORILLA-KernelSU-Companion-0.1.0.zip` and `app-debug.apk` from a successful GitHub Actions artifact.
2. In KernelSU Manager, install the ZIP as a module and reboot.
3. Install the APK on ARM64 Android API 26 or newer.
4. Open GORILLA Companion and approve the root prompt for status/log access.

START opens the app's local synthetic scene. AIM settings are stored locally and are not applied to PUBG. ESP objects are demo data drawn inside this app. The module does not alter system partitions, PUBG files, process memory, touch input, or anti-cheat. PUBG KR 4.7 compatibility is not certified.
